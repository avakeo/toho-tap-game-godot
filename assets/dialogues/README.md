# 会話データの編集ガイド

## ファイルの場所と命名

```
assets/dialogues/<操作キャラID>/<操作キャラID>_vs_<敵キャラID>_<種類>.csv
```

例: `reimu/reimu_vs_marisa_talk2.csv` = 霊夢を操作して魔理沙と戦うときの会話。

キャラID: `reimu` `marisa` `sakuya` `reisen` `sanae` `youmu`

## 種類と再生タイミング

| 種類 | タイミング |
|---|---|
| `talk1` | バトル開始前（開幕会話） |
| `talk2` | 1形態目を倒した直後 |
| `talk3` | 2形態目を倒した直後 |
| `win` | 最終形態を倒した後（勝利会話） |
| `lose` | 自分のHPが0になった後（敗北会話） |

- **ファイルが無い**場合、その会話はスキップされて次に進みます（エラーにはなりません）。
- 本文が「会話が用意されていない」の行は**未執筆プレースホルダ**として無視されます。

## CSVフォーマット

1行目はヘッダ。2行目以降が台詞です。文字コードはUTF-8。

```csv
"speaker","text","expressions"
"霊夢","あら、思ったより余裕ね","warai"
"魔理沙","これでもくらいな！","shinken"
"# ここはメモ行。ゲームには表示されない",""
```

| 列 | 内容 |
|---|---|
| speaker | 話者名。`霊夢` のような表示名でも `reimu` のようなIDでもOK |
| text | 台詞本文。カンマや改行を含む場合は `"..."` で囲む |
| expressions | 表情タグ（下記）。空欄なら通常の立ち絵 |

- `#` で始まる行はコメントとして無視されます。
- 話者名がその対戦カードの2人と一致すると、立ち絵のハイライト・表情切り替えが働きます。

## 表情タグ

| タグ | 表情 |
|---|---|
| （空欄） | 通常 |
| `shinken` | 真剣 |
| `ressei` | 劣勢・ダメージ |
| `odoroki` | 驚き |
| `warai` | 笑い・余裕 |

表情スプライトの実体は `resources/characters/<キャラID>.tres` の
`tatie_expressions` で登録されています。差分を追加したい場合はそこに
キーとテクスチャを足せば、CSVからそのキー名で使えるようになります。

## 検証ツール

執筆状況の一覧と、話者名・表情タグのミスをチェックできます。

- Windows: `tools/validate_dialogues.bat` をダブルクリック
- コマンドライン: `godot --headless --path . -s tools/validate_dialogues.gd`
