# 効果音（SE）ファイル置き場

このフォルダに以下のファイル名で音声ファイル（ogg / mp3 / wav）を置くと、
ゲーム起動時に自動で読み込まれて再生されます。ファイルが無い場合は何も鳴りません。

| ファイル名 | 再生タイミング |
| --- | --- |
| `attack.ogg`（または .mp3 / .wav） | 敵にダメージを与えた時（タップ攻撃） |
| `damage.ogg`（または .mp3 / .wav） | 自キャラがダメージを食らった時 |

- 読み込み処理は `scenes/game/game.gd` の `_load_se()` にあります。
- SEの音量はメニューの「設定 → SE（効果音）音量」で個別に調整できます（専用の SE バスで再生）。
